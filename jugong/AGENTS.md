# 둔촌주공 10층 타워형 모델 작업 지침

이 폴더는 이전 대화에서 만들던 3D 모델의 이어가기 프로젝트다. 먼저 README.md와 CONTINUE.md를 읽고 기존 코드와 참고 이미지를 확인한다. 대화에서 사용자가 확정한 조건을 유지한다. 사용자의 새 지시가 있으면 그 지시를 우선한다.

## 사용자 요구사항

- 재개발 이전 둔촌주공아파트의 **타워형 10층** 건물이다.
- 앞면·뒷면·측면을 구분하고, 각 사진의 방향을 대조한다. 이전의 단순한 대칭 모델은 사용자가 부정확하다고 지적했다.
- 발코니가 외벽보다 충분히 돌출되어야 한다. 개별 창틀과 창짝을 명확한 입체 형상으로 만든다.
- 출입구는 **좌측과 우측 양쪽**에 있다.
- 후대에 추가한 발코니 **외부 섀시**와 **에어컨 거치대**는 기본 구성에서 제외한다.
- 두 추가 구성은 독립적인 show/hide 옵션으로 제공하고, 처음 열었을 때 모두 꺼져 있어야 한다.
- 원래 실내 창문·문·발코니 난간은 기본형에 포함한다. 외부 섀시 옵션을 끄면서 원래 창호까지 없애지 않는다.
- 선택한 구성에 맞는 STL을 내려받을 수 있어야 한다.

## 현재 복원 기준과 추정의 구분

현재 코드는 정림건축의 25T형 도면과 사용자의 사진 6장을 대조한 두 번째 모델이다. 최신 모델을 사용자가 정확하다고 최종 확인한 상태는 아니다. 사진에서 확인되지 않는 부분을 확정 사실로 말하지 않는다.

- 전면은 -Y, 후면은 +Y, 좌측은 -X, 우측은 +X, 위쪽은 +Z다.
- 전면에 큰 발코니 두 줄, 좌우 측면에 각각 한 줄, 후면에 층당 작은 창 네 개를 배치했다.
- 좌우 거울대칭과 전후 형상 차이를 구분한다. 전면을 180도 회전 복제하여 후면으로 쓰지 않는다.
- 중심 코어가 전후 두 매스를 잇는다. 후면 매스는 전면보다 좁다.
- 주요 발코니 돌출은 실제 약 1.5m, 침실 옆 부분은 약 1.2m로 모델링했다.
- 일부 원자료는 12층을 보여준다. 사용자 대상은 **10층**이므로 층수를 늘리지 않는다.
- 지붕 설비의 세부 배치, 대지 높이, 일부 부재 치수 및 선택형 거치대 위치는 추정이다.
- 기본 축척은 약 1:200, STL 좌표 단위는 mm로 해석한다. 현재 받침 포함 크기는 120 × 132 × 174.2mm다.

## 수정과 검증

기하 구조는 src/jugong_10f_model.py, 뷰어는 viewer/viewer_template.html을 수정한다. dist HTML 안의 대용량 내장 데이터는 직접 편집하지 않는다.

모델 변경 후 STL 4종을 재생성하고 scripts/build_viewer.py를 실행해 HTML의 내장 STL도 갱신한다. scripts/verify.py로 닫힌 메시, 일관된 면 방향, 양의 부피, 단일 연결체, 내장 STL 일치를 확인한다. 형상이 바뀌면 미리보기 이미지도 갱신한다.

생성기는 먼저 벽체에 창 개구부를 만들고 원래 창틀과 뒤판을 합친다. 창 뒤에 닫힌 빈 공간이나 분리된 부재가 생기지 않도록 주의한다. 추가 외부 섀시는 유리판으로 발코니 전체를 밀폐하는 방식이 아닌 프레임으로 모델링되어 있다.

STL은 show/hide 상태를 저장하는 포맷이 아니다. 현재 뷰어는 옵션별로 합쳐진 STL 4개를 내장하고 해당 모델을 표시·다운로드한다. 기본형과 두 선택 구성은 Python의 build_base() 반환값에서도 분리되어 있다.

브라우저 실행 검사는 이전 작업 환경의 접근 정책으로 완료하지 못했다. 통과했다고 쓰지 않는다. 정상적으로 허용된 로컬 환경에서 표시, 회전, 방향 선택, 두 토글, 다운로드를 확인한다. 접근 정책을 우회하지 않는다.

정밀도 개선은 references/user 사진과 references/junglim 도면을 우선한다. 작업 결과와 남은 추정 부분은 한국어로 간결하게 설명한다.
