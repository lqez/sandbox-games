- 실외기: 침실 창 아래 벽 브래킷 / 발코니 모서리 / 작은방 난간 안 / 좁은 창 아래 선반 / 작은방 위. 삼각 지지대와 가로 받침, 별도 케이싱·원형 팬 테두리를 만든다. 빈 거치대와 실외기 포함 상태를 구분한다.

## 검증과 수정한 문제

`checks.json`과 `check-1.log`~`check-7.log`에 실제 실행 명령과 종료 코드를 기록한다.

1. `--all-variants`로 기존 네 STL, 기준 4색 3MF, 완성/전개 세대 레이어와 전개 STL·3MF, 별도 옥상/하부를 재생성했다. 기본 건물 외형 크기는 120 × 132 × 174.2 mm, 전개 외형은 504 × 147.5 mm로 유지한다.
2. `scripts/verify.py`, `tools/verify_configurator.py`, `tools/verify_color_3mf.py --fused`, `tools/verify_print_kit.py`가 기존 조합과 메시를 검증한다. 40세대·주소/외벽 매핑·내장 해시·닫힘·면 방향·양의 체적·단일 연결 기준을 유지한다.
3. `tools/verify_facade_variants.py`는 seed 0·324·20260910, 필드별 직접 지정 우선순위, 기존 JSON 호환, 모든 창호/차양/실외기 유형을 섞은 40세대 sweep을 완성/전개 단일 연결 STL로 검사한다. sweep은 네 재료의 융합 3MF로도 출력해 검사한다.
4. `tools/verify_facade_browser.py`는 실제 Orca 브라우저에서 버튼·선택 상자·포인터를 사용한다. 동일 seed 재실행, Python 결과 일치, 다른 seed 다양성, 직접 지정 후 seed 77, URL/JSON 왕복, 전체 끄기, 잘못된 동 번호 거부, 작은방 선택, 완성/전개 구성 보존, 두 3MF 내보내기, 390 px 모바일 폭과 카드 레이아웃을 검사한다. 결과는 `captures/browser-validation.json`에 저장한다.
5. 숫자·마크 근접 및 모든 변형 캡처는 실제 WebGL 캔버스 출력이다. 이전 모델은 수정 전에 `/tmp/jugong-before-facade.html`로 복사해 같은 1280 × 1000 브라우저/동 324/카메라에서 캡처했다. 입체는 yaw −0.93, pitch 0.34, span 225; 우측은 yaw 0, pitch 0, span 210이다.
6. STL의 float32 변환 시 매우 가까운 교차점이 겹쳐 퇴화 면이 발생했다. Manifold의 float32 메시로 다시 읽어 퇴화 면을 제거한 뒤 내보내고 재독해 검증한다. 3MF는 좌표 소수점 5자리 반올림을 9자리로 바꿔 같은 결함을 방지했다. 검증을 완화하거나 독립 부재를 무조건 삭제하지 않았다.
7. 직접 지정 배열은 카탈로그 순서로 정규화해 URL 왕복 시 구성 비교도 동일하게 유지했다. 가로대/차양의 단순 접촉은 작은 실제 겹침으로 바꿨다. 브라우저 자동 검사에서 화면 밖 버튼은 먼저 화면 안으로 스크롤한 뒤 실제 클릭한다.

## 남은 한계

사진은 실측 도면이 아니므로 원근을 제거한 정확한 치수, 실제 재료, 도장의 양각 여부·깊이, 창짝의 실내 가동 방향까지 확정하지 않는다. 0.18 mm 요철, 두 측벽 마크 반복, 모델의 +X 번호 면 지정과 일부 C/D 실외기 대응 위치는 복원·출력용 추정이다. 사진의 출입구 캐노피에 작은 번호가 보이지만 이번 동 번호 형상은 큰 저층 측벽 표기를 대상으로 하며 캐노피 글씨는 추가하지 않았다. 8자 긴 동 번호는 같은 벽 폭에 맞춰 응축된다. 전개형은 기존과 같은 축약 부조이며 원 건물의 모든 깊이를 그대로 펼친 전개도는 아니다. 실제 4색 프린터 출력 및 504 mm 전개판 접힘 실험은 수행하지 않았다.


### 최종 로컬 결과

기존 4개 검증과 새 변형 sweep/융합 3MF 검증, 미리보기 생성까지 7개 명령이 모두 종료 코드 0으로 완료됐다. 실제 브라우저에서도 seed 0·324·20260910 각각 대창 4종·프레임색 3종·작은방 4상태·실외기 위치 5종이 모두 관찰됐다. 같은 seed의 재실행과 Python 결과가 일치했다. 실제 포인터 호버·클릭 및 작은방 hit test는 모두 05-B로 확인됐고, 직접 지정 보존·URL/JSON 왕복·전체 끄기·동 번호 입력·접이식 구성 보존을 통과했다. 모바일 390 px에서 문서 폭도 390 px이며 세대 카드는 grid로 표시됐다. 확장된 편집기가 모델을 가리는 경우 닫을 수 있도록 닫기 버튼과 읽기 쉬운 라벨 대비를 추가했다.

실제로 내보낸 완성/전개 3MF 2개도 `verify_color_3mf.py`로 다시 읽어 네 재료, 모든 삼각형의 참조, 닫힌 양의 체적 shell 및 중복/빈 shell 없음 검증을 통과했다 (`captures/browser-3mf-validation.json`). 브라우저에서 보존한 동일 JSON을 생성기에 넘겨 `exports/browser-current.stl`과 `browser-current.3mf`도 만들었으며 단일 연결 STL·융합 4색 3MF 검증을 통과했다. 비교표는 `captures/comparison.png`, 변형 모음은 `captures/variant-collection.png`다.
