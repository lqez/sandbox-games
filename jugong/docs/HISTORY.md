# 재개발 전 둔촌주공아파트 시설물 이력 조사

조사일: 2026-09-08

이 문서는 현재 10층 타워형 복원 모델에 단지 맥락과 동별·세대별 선택 기능을 더하기 위한 1단계 조사다. 공개된 공식 기록, 프로젝트에 보관된 사용자 사진, 2차 자료를 서로 섞지 않고 아래처럼 표시한다.

- **확인**: 공식 기록의 목록·도면·고시 또는 사진에 직접 보이는 내용
- **사진 추론**: 촬영 시점·방향이 완전히 확인되지 않은 사진에서 읽은 내용
- **미확인**: 주민 기억이나 다른 주공단지 사례로는 가능하지만 이번 조사에서 둔촌주공의 1차 자료를 찾지 못한 내용

## 핵심 결론

1. 둔촌주공은 1976년 저층형 설계 기록, 1978년 고층형 설계 기록, 1979년 상가·관리소·보일러실 및 조경 공사 기록, 1980년 옥외전기 공사 기록이 이어지는 단계적 사업이었다. 한 시점의 배치도만으로 모든 시설의 최종 상태를 설명할 수 없다.
2. 1980년 3월 2단지, 같은 해 11월 1·3·4단지의 입주가 이루어졌다. 공식 자료끼리도 주거동 수를 145개동과 164개동으로 다르게 집계하므로, 부속동 포함 여부를 확인하기 전에는 어느 수치도 전체 주거동 번호표로 사용하지 않는다.
3. 10층 타워형의 동 번호는 프로젝트 사진에서 **302동, 324동, 420동**이 직접 확인된다. 이 세 번호 외의 후보 목록은 공개 배치도의 동 번호를 판독하지 못해 확정하지 않는다.
4. 단지에는 상가, 관리사무소, 지하 기계실, 보일러 관련 시설, 동사무소, 경비초소, 놀이터와 조경 시설, 옥외등, 도로·보행 공간, 학교가 존재했음이 공식 기록으로 확인된다. 급수탑, 유치원, 경로당의 옛 위치와 형태는 이번 공개자료 조사에서 확인하지 못했다.
5. 후대 사진의 외부 섀시와 에어컨/거치대는 세대마다 상태가 다르다. 따라서 모델의 기본형은 원래 창호와 난간을 유지하고, 동 번호와 세대별 후대 부착물은 별도 구성 데이터로 다루는 것이 맞다.

## 동 배치와 번호 근거

### 확인된 체계

- 단지는 1·2·3·4단지로 나뉘었고 입주 시점도 2단지와 1·3·4단지가 달랐다.
- **사진 추론**: 동 번호의 백 단위가 단지 번호를 나타낸다. 프로젝트 사진의 302·324는 3단지, 420은 4단지라는 기존 파일 설명과 일치한다.
- **사진 확인**: `references/user/01_19-02-55.png`의 외벽에서 302, `05_19-03-22.png`에서 324, `03_19-03-08.png`와 `04_19-03-15.png`에서 420을 읽을 수 있다. 세 건물 모두 10개 주거층과 동일 계열의 H/T형 타워 매스를 보인다.
- **사진 추론**: 420동 항공 사선 사진 오른쪽 인접 건물에는 419로 보이는 표기가 있지만 해상도 때문에 확정 번호 목록에는 넣지 않는다.

### 아직 입증되지 않은 부분

- 서울기록원에는 `둔촌아파트 배치도`(RG6-SR108-FI121-IT9671)와 관리사무소 수집 `배치도`(RG6-SR108-FI124-IT9729)가 있으나, 웹 공개 페이지는 목록 정보만 제공하고 원문은 부분 제한이다. 따라서 전체 동 번호와 각 형식의 대응표를 이번 단계에서 만들 수 없다.
- 강동구청은 기존 현황을 지상 5~10층, 164개동, 5,930세대로 적고 서울기록원은 2015년 기준 145개동, 5,930세대로 적는다. 19개동 차이가 상가·관리·기계 등 부속동 집계 때문인지 확인되지 않았다.
- 현재 모델의 형식을 302·324·420 외 특정 동으로 표시하려면 먼저 공식 배치도 원문, 관리사무소 위치도 또는 동별 건축물대장을 열람해야 한다.

### 모델 입력으로 쓸 수 있는 안전한 범위

동 번호 UI의 초기 선택지는 `미지정`, `302`, `324`, `420`, `직접 입력`으로 제한한다. 직접 입력값은 외벽 명판 텍스트만 바꾸고, 확인되지 않은 동 번호가 선택됐다고 해서 건물 형상이나 단지 위치까지 사실로 표시하지 않는다.

### 동 번호 표식의 위치와 글리프 해석 (2026-09-09)

기존 옥상 코어 명판은 사진 근거와 맞지 않아 제거했다. 사용자 사진 네 장에서 번호는 발코니가 아닌 큰 빈 측벽의 저층부, 측면 작은 창 열 옆에 흰 바탕과 짙은 숫자로 보인다. 촬영 방위가 없으므로 모델의 `+X` 빈 측벽을 대표 위치로 택했으며 이는 방위 확정이 아니라 사진에 보인 면 구성의 대응이다.

사진별 세로 위치 차이를 그대로 남겨 302는 모델 Z 44.0 mm, 324는 39.5 mm, 420은 25.5 mm에 둔다. 직접 입력은 가장 온전하게 읽히는 324동의 39.5 mm를 기본 위치로 쓴다. 사진의 원근·수목 가림과 철거 상태 때문에 오차 범위는 대략 한 층이며, 더 좋은 정면 사진이 확보되면 이 세 값만 교정할 수 있다.

숫자는 시스템 폰트를 호출하지 않는다. 302·324·420에서 공통으로 보이는 좁고 굵은 산세리프 비례, 열린 4, 대각선 2, 길쭉한 0, 잘린 획 끝을 규칙으로 삼아 `0`~`9`와 하이픈의 프로젝트 전용 중심선 벡터를 정의했다. 7.0 mm 높이, 약 0.945 mm 획, 0.62 mm 양각이며 긴 직접 입력은 17.4 mm 폭 안에서 가로만 축소한다. 화면 완성형·전개형과 Python STL/3MF 생성기가 같은 좌표·획 규칙을 사용한다.

## 사진과 도면의 관찰 범위

### 사용자 제공 사진

사진 파일은 촬영 원본이 아니라 2026-09-08 대화에서 받은 스크린샷이며 원 촬영일·촬영자·정확한 방위가 없다. 그러므로 보이는 형상만 사용한다.

- 302동: 10개 주거층, 한쪽의 연속 발코니와 작은 창 열, 중앙 코어 및 옥상 매스가 보인다.
- 324동: 10개 주거층, 발코니별로 외부 섀시와 에어컨/거치대 설치 상태가 서로 다르다. 철거 전 성숙한 수목이 저층부를 가린다.
- 420동: 철거 중 사진에서 앞·옆 두 면의 비대칭 발코니와 옥상 형상을 볼 수 있다. 항공 사선 사진은 주변 동과 철거 시점의 공간 간격을 보여 주지만 방위는 확정하지 않는다.

### 정림건축 자료

[정림건축 ‘둔촌아파트’](https://junglim.info/archives/6466)의 25T형 평면·단위세대·입면 성격 도면·투시도·준공사진·전경·외벽상세를 사용한다. 프로젝트 안의 복제본은 형상 대조용이며, 저작권 이미지를 새 문서에 재수록하지 않는다. 일부 수직 도면과 투시도는 12층이므로 사용자의 10층 대상과 구분한다.

### 서울기록원 배치도와 항공사진 후속 확인

서울기록원 웹 목록의 배치도 원문은 부분 제한되어 동 번호를 읽을 수 없다. 서울시 항공사진 서비스의 연도별 영상도 이번 자동 조사에서 특정 촬영편·방위를 안정적으로 고정하지 못했다. 후속 조사에서는 1979-1980 준공기, 1990년대 주차 증가기, 2015-2018 이주 전후의 세 시점을 같은 좌표로 비교하고, 링크·촬영일·촬영방향만 기록한다.

## 모델링 우선순위

1. **형상 기준 보존**: 현재 두 번째 복원 모델의 10층, 양측 출입구, 전·후·측면 비대칭, 돌출 발코니, 원래 창호·난간을 회귀 검증 대상으로 고정한다.
2. **동 번호를 형상에서 분리**: 확인된 302·324·420과 직접 입력을 명판 레이어로 제공한다. 특정 번호가 특정 위치·형식을 증명한다는 메타데이터는 근거가 있을 때만 추가한다.
3. **세대 키 정의**: 10층 × 층당 4세대의 안정된 내부 키(`01-A`~`10-D`)와 외벽의 발코니/창 열 매핑을 먼저 만든다. 실제 호수 표기는 동별 자료 확보 전에는 가상 키와 분리한다.
4. **세대별 후대 상태**: 각 세대의 외부 섀시는 `없음/부분/전체`, 냉방기는 `없음/거치대만/실외기 포함`으로 독립 저장한다. 기본값은 모두 `없음`이다.
5. **4색 재료 체계**: 본체 콘크리트, 창호·난간, 유리/외부 섀시, 후대 부착물·명판의 최대 4재료 그룹을 제안한다. 색은 역사적 사실과 출력용 식별색을 구분하고 사용자가 팔레트를 바꿀 수 있게 한다.
6. **출력 포맷**: STL은 색·재료를 저장하지 못하므로 단색 호환용으로 유지하고, 4색 출력은 3MF의 재료/부품 그룹을 우선한다. 표면 질감은 사진의 오염을 그대로 굴곡으로 복제하지 말고 출력 축척에서 살아남는 낮은 양각 패턴으로 시험한다.
7. **조합 폭발 방지**: 세대별 모든 경우의 수를 미리 융합 STL로 만들지 않는다. 기본 구조와 세대별 섀시·거치대·실외기·명판을 주소 가능한 레이어로 만들고 선택 구성에서 3MF를 조립하는 방식이 필요하다.
8. **단지 시설은 별도 단계**: 공식 배치도 원문을 확보한 뒤 지형·보차 동선·조경을 먼저 만들고, 상가·관리·기계·경비·놀이터 순으로 배치한다. 급수탑·유치원·경로당은 근거 확보 전 모델링하지 않는다.

## 후속 열람 요청 목록

1. 서울기록원 RG6-SR108-FI121-IT9671 및 RG6-SR108-FI124-IT9729 배치도 원문
2. RG6-SR106-FI128의 상가·관리소·보일러실 도면과 2단지 수목·시설물 배치도 원본
3. RG6-SR106-FI110의 3·4단지 옥외등 배치도 원본 및 중간전기실 범례
4. 연도미상 위생·난방·가스 도면철의 급수·물탱크·기계 시설 도면
5. 강동구 또는 건축물대장의 302·324·420동 층별 호수표와 승강기 증설 기록
6. 서울시 항공사진 서비스의 1979-1980, 1990년대, 2015-2018 촬영편

## 4색 출력용 표면 해석

사용자 사진과 정림건축 준공·상세 사진에서 확인 가능한 큰 색·재료 관계만 사용한다. 촬영 시기·화이트밸런스가 서로 달라 아래 색은 역사적 도료 번호의 복원이 아니라 출력용 대표색이다.

| 슬롯 | 관찰 | 출력 해석 |
|---:|---|---|
| 0 | 외벽은 순백보다 따뜻한 회백·미색이며 후대 사진에서 빗물 자국, 도장 퇴색, 넓은 보수 면이 보인다. | `#B7B09C` 노후 콘크리트. 미세 얼룩 비트맵 대신 폭 3.8 mm 이상, 깊이 0.4 mm의 소수 relief를 둔다. |
| 1 | 원래 난간과 여러 시기의 창틀은 외벽보다 어두운 회색·회녹색으로 읽힌다. | `#6E7773` 창호·난간 금속. 선택 외부 섀시도 같은 구조 슬롯에 배정한다. |
| 2 | 발코니 안쪽, 창 유리, 열린 개구부는 가장 어두운 청회색 영역을 만든다. | `#334348` 유리·어두운 개구부. 투명 재료를 요구하지 않고 불투명 다색 출력에서도 대비가 남게 한다. |
| 3 | 준공 사진과 후대 사진의 옥상 코어는 외벽보다 따뜻한 갈색 계열이며 실외기·배관·부착물도 별도 시기 층위로 읽힌다. | `#8A4F37` 옥상·출입구·후대 부착물·명판 accent. 근거가 다른 요소를 형상 메타데이터에서는 계속 구분한다. |

네 슬롯은 색상 교체가 가능하지만 재료 인덱스와 형상 분류는 고정한다. 이는 UV 이미지 한 장에 의존하지 않고 3MF `basematerials`와 삼각형별 속성으로 슬라이서에 전달된다.
