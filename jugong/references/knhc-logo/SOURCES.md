# 옛 대한주택공사 마크 근거

- 한국토지주택공사 토지주택연구원, 《공공임대주택 브랜드 적용방안 연구》, 연구기획 2023-099, 인쇄 29쪽 / PDF 47쪽의 `주공아파트` 심벌. [공공 건설기술정보시스템 원문](https://www.codil.or.kr/filebank/original/RK/OTKCRK240295/OTKCRK240295.pdf). `lhri-old-knhc.png`는 해당 페이지에 내장된 마크 이미지(69 × 60 px)를 원본 픽셀 그대로 추출한 것이다. 외곽 원, 수평 지붕마루, 뾰족한 문머리 및 흰 집/어두운 원 구성을 모델의 직접 근거로 쓴다.
- 대한주택공사, 《HOUSING STATUS 1981》 표지. [공공 건설기술정보시스템 원문](https://www.codil.or.kr/filebank/original/EC/OTKNEC000981/OTKNEC000981.pdf). `knhc-1981-positive.png`는 표지 마크의 확대 영역으로, 원형 테두리와 집을 함께 인쇄한 양화 버전이다. 현재 모델의 음화 버전과 동일한 원형·평평한 지붕마루를 교차 확인했다.
- 검색 중 발견한 나무위키 미러의 1978~2003 SVG는 파일 서버가 정상 벡터를 반환하지 않아 직접 사용하지 않았다. 인증된 CI 제도용 원본 벡터를 확보했다고 주장하지 않는다.

래스터의 원근 왜곡 없는 원형과 주요 직선/대칭점을 측정해 코드 도형으로 옮겼다. 외곽의 가로:세로는 1:1로 고정하며 내부 윤곽의 세부 오차는 소스 해상도(약 1 px)에 제한된다. 원문 PDF 전체는 재배포하지 않는다.
