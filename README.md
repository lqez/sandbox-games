# sandbox-games

a series of minigames — 정적 파일만으로 동작해서 GitHub Pages로 바로 플레이할 수 있습니다.

## 게임 목록

| 게임 | 설명 | 플레이 |
| --- | --- | --- |
| 🛠 [PURATANK](./puratank/) | three.js로 만든 SD 플라모델 스타일 턴제 탱크 전투 | `/puratank/` |
| 📚 [BOOKFIGHT](./bookfight/) | 책끼리 발췌문으로 입씨름하는 3D 격투 중계 (단판 1라운드) | `/bookfight/` |

## GitHub Pages 설정

1. 리포지터리 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main` / `/ (root)` 선택
3. `https://<계정>.github.io/sandbox-games/` 에서 게임 목록 확인

## 로컬 실행

빌드 과정이 없으므로 정적 서버만 있으면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000/puratank/
```

## PURATANK 조작법

- **파란 칸 클릭**: 이동 — 지형(풀·흙·모래·진흙·강 도하)과 경사, 궤도 선회 비용에 따라 이동 범위가 달라짐
- **적/수목/건물/지면 클릭**: 포격 — 사거리 + 포신 부앙각(-14°~+20°) + 능선/건물 차폐 + 수목 엄폐를 반영한 명중률 표시
- **차체 레벨 = 장갑(피해 감소), 조종 레벨 = 회피(명중률 감소)**
- 수목·농가·대전차 장애물·모래주머니 등 WW 프랍은 전부 파괴 가능, 포격 지점엔 크레이터가 생겨 지형이 낮아짐
- 드래그로 카메라 회전, 휠/핀치 줌, 우클릭 드래그로 이동
- `?seed=1234` 로 맵 시드 고정 가능

## BOOKFIGHT 규칙

책 두 권을 옥타곤에 올려 **입씨름으로 붙이는 45초 초단판 권투**. UFC 중계처럼 보여줍니다.
16권 모두 퍼블릭 도메인 고전이고, 쪽수·출간연도·저자는 실제 값입니다.

- **45초 3막** — 펀치는 쉬지 않고 오가고, 그 위에 설전 3합이 얹혀 치명타를 만듭니다
- **설전은 하나로 이어지는 논쟁입니다** — 1합 탐색 → 2합은 1합을 물고 되받기
  (「그 말, 그대로 돌려드리지」) → 3합은 처음 들었던 말을 콜백해 결정타
  (「나더러 어렵다 하셨소. 그 말은 마지막 문장으로 갚겠소」)
- **말싸움에서 이겨야 주먹이 들어갑니다** — 상대 책의 약점(`#장황함` `#유치함` `#편협` …)을 찌르고,
  상대는 그 약점을 변호합니다. 논파당하면 공수가 뒤집혀 역으로 얻어맞습니다
- **어떤 책이든 싸울 수 있습니다** — 쪽수·출간연도·장르만 있으면 도발/방어 대사가 자동 생성되고,
  큐레이션된 16권은 전용 대사가 우선합니다
- **분량 = 체력·체급·기동력** — 두꺼우면 맷집이 좋지만 느리고, 얇으면 선공을 자주 잡습니다
- **출간연도 = 관록** — 오래 살아남은 책일수록 피해를 덜 받습니다
- **저자의 성격 = 필살기** — 드라큘라는 흡혈, 카프카는 불안 잠식, 다윈은 경기가 길어질수록 진화
- **45초 단판** — 다운 2회면 TKO, 시간이 다 되면 심판 3인 채점 (실측 KO 81% / 판정 19%)
- **시드가 승부를 가릅니다** — 시드가 컨디션과 전개를 정합니다. 전체 120개 대진 모두
  시드에 따라 승자가 뒤집힙니다. `?seed=100001&red=mobydick&blue=alice` 로 경기를 공유하세요
- 경기 중 **배속 / 자유 시점 / 건너뛰기** 조작 가능

자세한 설계는 [bookfight/DESIGN.md](./bookfight/DESIGN.md) 참고.
