# PLOH 전투 시제품

세로 화면 기본의 방치형 자동 전투에 한손 개입(궁극기 탭, 연계, 방어 타이밍)을 더한 Godot 4.4 시제품입니다. 캐릭터는 원작 리소스 대신 코드로 그린 임시 실루엣이고, 이름도 역할명(창기사, 수호기사, 물의 무녀)을 씁니다.

## 플레이

- **자동 전투**: 기본으로 켜져 있습니다. 영웅들이 전술 규칙에 따라 궁극기와 방어까지 알아서 씁니다.
- **궁극기**: 게이지가 찬 영웅 초상화를 탭합니다. 3초 안에 다른 영웅의 궁극기를 이어 쓰면 연계(CHAIN)가 쌓여 피해가 25%씩 늘어납니다.
- **방어**: 보스가 균열 폭발을 예고하면, 노란 구간에서 방어를 누릅니다. 완벽 방어는 피해를 85% 줄이고 반격합니다. 자동 방어는 일반 방어(50%)까지만 노립니다.
- **전술 규칙**: 영웅별 자동 궁극기 규칙을 켜고 끕니다.
- **키보드**: 1·2·3 궁극기, Space 방어, A 자동 전환, R 다시 시작

## 빌드

```sh
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless --path ploh/game --import
$G --headless --path ploh/game --export-release "Web" ../play/index.html
```

스레드 없는 웹 템플릿(`web_nothreads_release.zip`)을 쓰므로, GitHub Pages처럼 COOP/COEP 헤더를 줄 수 없는 정적 호스팅에서도 돌아갑니다. 폰트는 Noto Sans KR(OFL)을 KS X 1001 한글 2,350자 범위로 줄여 넣었습니다.

## 구조

- `scripts/main.gd`: 전투 로직(행동 게이지, 궁극기와 연계, 보스 예고와 방어, 페이즈)
- `scripts/field.gd`: 전장 그리기와 화면 방향별 유닛 배치
- `scripts/hud.gd`: UI와 입력. 세로는 하단 엄지 패널, 가로는 오른쪽 조작 막대
