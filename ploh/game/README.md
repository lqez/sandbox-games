# PLOH 액션 전투 시제품

아이소메트릭 시점의 3D 액션 RPG 전투를 한 손 제스처만으로 즐기는 Godot 4.4 시제품입니다. 카메라는 디아블로처럼 방향을 고정하되 더 낮고 가깝게 잡아 캐릭터를 크게 보여 주고, 주변 적이 많으면 자동으로 물러나 여러 적을 한꺼번에 담습니다.

캐릭터와 배경은 원작 리소스 대신 기본 도형으로 조립한 로우폴리 임시 모델이고, 이름도 역할명(창기사, 수호기사, 물의 무녀)을 씁니다.

## 조작

이동은 자동입니다. 영웅이 가장 가까운 적에게 알아서 붙습니다. 플레이어는 화면 어디서든 세 가지 제스처로 싸웁니다.

| 제스처 | 동작 |
|---|---|
| 터치 | 4단 콤보 공격. 영웅 주위의 박자 링이 금색일 때 누르면 JUST 강화타 |
| 롱터치 | 차지. 손을 떼면 회전베기 |
| 드래그 | 그 방향으로 회피 대시. 대시 직후 터치하면 돌진베기 |

- **저스트 회피**: 적 공격이 맞기 직전에 피하면 슬로모션이 걸리고 다음 타격이 강화됩니다.
- **카운터**: 적의 공격 예고(바닥 원)가 금색으로 바뀐 순간에 때리면 적이 경직됩니다.
- **교대**: 3인 파티를 바꿉니다. 들어오는 영웅이 착지 일격(교대 연계)을 씁니다.
- **궁극기**: 타격으로 게이지를 채워 씁니다.
- **자동**: 오른쪽 위 스위치를 켜면 박자 없이 콤보를 이어 가는 자동 전투가 됩니다.
- **키보드**: Space/J 터치, 방향키·WASD 회피, Q 교대, E 궁극기, T 자동, R 다시 시작

웨이브 3개 뒤에 보스 '균열의 군주'가 나옵니다.

## 빌드

```sh
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless --path ploh/game --import
$G --headless --path ploh/game --export-release "Web" ../play/index.html
```

스레드 없는 웹 템플릿(`web_nothreads_release.zip`)을 쓰므로, GitHub Pages처럼 COOP/COEP 헤더를 줄 수 없는 정적 호스팅에서도 돌아갑니다. 렌더러는 웹용 Compatibility(WebGL 2)입니다. 폰트는 Noto Sans KR(OFL)을 KS X 1001 한글 2,350자 범위로 줄여 넣었습니다.

## 구조

- `scripts/game.gd`: 전장과 카메라, 파티 교대, 웨이브, 피해 처리, 히트스톱·슬로모션·흔들림 연출
- `scripts/hero.gd`: 자동 이동, 콤보와 JUST 판정, 차지, 회피 대시, 저스트 회피
- `scripts/enemy.gd`: 추적, 공격 예고와 내려치기, 카운터 경직
- `scripts/hud.gd`: 제스처 인식(터치·롱터치·드래그), 박자 링, 파티·콤보·보스 HP 표시
- `scripts/fx.gd`: 로우폴리 캐릭터 조립과 연출용 메시
