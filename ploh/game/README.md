# PLOH 액션 전투 시제품

세로 화면에서 한 손으로 즐기는 아이소메트릭 3D 액션 RPG 전투 시제품입니다(Godot 4.4, 웹). 영웅 프라우가 지하 미궁의 방 다섯 개를 자동으로 지나며 방마다 갈루스 제국 병사를 정리하고, 마지막 방에서 보스 요슈아와 싸웁니다.

빨리 누르는 게임이 아니라 타이밍과 패턴의 게임입니다. 누르면 0.28초 뒤 칼이 닿을 만큼 바로 반응하고(예비 동작 약 0.17초 + 베기 약 0.1초), 박자(120 BPM)는 보상입니다. 박자에 정확히 맞춘 타격은 JUST가 되고, 서둘러 누른 타는 약해집니다. 적의 내려치기는 박자에 떨어집니다.

## 조작

이동은 자동입니다. 화면 어디서든 제스처로 싸웁니다.

| 제스처 | 동작 |
|---|---|
| 터치 | 기본 공격. 3콤보 고리와 4콤보 고리(마지막은 피니시)를 번갈아 잇는다. 칼을 뻗은 뒤 0.74초 안에 누르면 이어진다. 박자 ±0.07초 안에 누르면 JUST 강화타(1.6배) |
| 따닥(0.14~0.3초 간격) | 지금 타 뒤에 빠른 베기를 끼워 넣는다 |
| 한 박 쉬고 터치 | 쉬는 박자 다음 박자에 정확히(±0.09초) 누르면, 쉬기 전에 친 수에 따라 돌진 찌르기(1타), 회오리 베기(2타), 섬광 연격(3타) |
| 롱터치 | 차지, 떼면 회전베기. 박자에 맞춰 떼면 강화 |
| 롱터치 후 드래그 | 그 방향으로 영웅 스킬 조준, 떼면 발동 |
| 플릭 | 싸우는 중이면 방향 공격(적 쪽: 돌진 찌르기, 반대쪽: 물러나 베기, 옆: 반월 베기). 적이 공격을 예고 중이면 언제나 구르기 회피 |
| 원 그리기 | 회오리 베기 |
| 드래그 | 직접 이동. 손을 떼고 0.8초 뒤 다시 자동 이동 |

- **입력 받아 두기**: 휘두르는 중에 누른 입력은 칼이 지나가자마자(최소 0.12초 뻗은 자세 뒤) 바로 낸다. 조작이 씹히지 않는다. 다만 칼이 아직 지나가는 중에 서둘러 누른 타는 0.8배, 한 타 사이에 거듭 누르면 JUST를 잃는다. JUST가 세 번 이어지면 그 타는 무거운 일격(긴 히트스톱, 큰 밀림, 두 배 피해)
- **탭과 플릭 가리기**: 누른 뒤 70ms 동안 손가락이 움직이지 않으면 탭이다. 플릭·드래그가 먼저 공격을 내지 않는다. 박자 판정은 누른 순간 기준
- **방패병**: 정면에서 오는 가벼운 타격은 방패로 막는다. 공격 예고 중이거나, 무거운 타격, 옆과 뒤는 뚫린다
- **저스트 회피**: 적의 칼날이 지나가는 순간 구르고 있으면 슬로모션과 다음 타 강화
- **카운터**: 적의 공격 예고가 금빛으로 달아오른 순간에 때리면 경직
- **교대, 궁극기, 자동 전투**: 구석의 작은 버튼
- **키보드**: Space/J 터치, WASD 이동, 방향키 플릭, Q 교대, E 궁극기, T 자동, R 다시 시작

## 타격 판정

타격은 애니메이션을 따릅니다(`scripts/weapon.gd`). 공격 클립마다 칼끝이 빠르게 움직이는 구간과 그때 칼날이 몸에서 떨어진 거리(사거리)를 재 두고, 그 구간 동안 칼날이 실제로 쓸고 지나간 면에 닿은 적과 소품만 맞습니다. 단계(예비, 베기, 머묾, 회복)는 클립의 실제 재생 위치로 나누고, 애니메이션은 물리 틱에 맞춰 진행해서 프레임이 밀려도 칼과 판정이 어긋나지 않습니다. 칼 궤적 리본도 같은 칼날 위치로 그립니다. 적의 공격도 같은 방식으로, 적의 칼날이 영웅을 지나갈 때만 피해가 들어갑니다.

## 몸과 무기의 무게

키프레임 위에 절차적 애니메이션을 덧입힙니다(`scripts/procedural.gd`, `scripts/ragdoll.gd`).
- **관성 이동**: 출발할 때는 몸을 앞으로 싣고, 빠를수록 크게 돈다. 빨리 달리다 급히 서거나 크게 꺾으면 미끄러지며 몸을 낮춰 버티느라 멈칫한다(6m/s에서 약 0.2초). 디딘 발은 그 자리에 붙잡는다. 달리다 공격하면 멈칫하지 않고 달리던 힘을 내딛기에 싣는다.
- **무기 무게**: 예비 동작은 끝에서 멈칫 힘을 모으고, 베기는 가속한다. 칼이 지나간 운동량이 상체를 끌고 비틀며 골반이 한 번 처진다. 벤 직후에는 칼이 잠깐 무겁게 움직인다.
- **피격**: 맞는 프레임에 상체가 바로 꺾이고, 히트스톱 동안 그 자세로 떨다가 스프링으로 되튄다. 처치하면 래그돌로 무너진다.
- **지형**: 바닥에 높낮이가 있고, 발은 두 관절 IK로 지형에 붙는다.

연출의 기준 수치는 레퍼런스 영상 분석에서 왔습니다(`../research/motion/reference/ANALYSIS.md`).
- 화면 전체를 멈추는 히트스톱은 없습니다. 레퍼런스처럼 공격자는 거의 멎지 않고(1~3프레임), 맞은 적이 조금 더(60~100ms) 멎으며 절차적으로 꺾입니다.
- 카메라 흔들림은 화면 너비 약 0.7%를 한 번 밀었다가 40~60ms 안에 돌아옵니다.
- 공격 클립은 예비 동작 0.85배 → 베기 1.8배 → 뻗은 자세 0.1초 유지 → 회복 순서로 시간을 재배치합니다.
- 보스와 정예를 처치하면 슬로모션, 다가가며 도는 카메라, 섬광, 큰 글자 연출이 나옵니다.

## 던전

`scripts/dungeon.gd`가 노이즈로 일그러뜨린 타원형 방과 휘어진 복도를 하나의 거리장으로 만들고, 0.5m 격자에서 등고선을 뽑아 벽과 바닥을 만듭니다. 배경은 던전밥 등을 참고한 아트 디렉션(`../research/dungeon/ART_DIRECTION.md`, 콘셉트 그림 `../research/dungeon/concept_*.png`)을 따릅니다: 동굴에 삼켜진 고대 성.
- **바닥**: 큰 판석(4m/장). 무작위 얼룩 대신 공간 정보로 칠합니다. 벽 가까이와 복도는 흙, 자동 이동 경로를 따라 닳은 판석입니다.
- **벽**: 아래 약 2.2m는 다듬은 성벽 돌, 그 위는 동굴 암반이고 윗선은 들쭉날쭉합니다. 카메라 쪽은 무너진 낮은 턱이라 방 안이 늘 트여 보입니다.
- **벽 너머**: 허공 대신 흙과 뿌리로 메운 땅입니다. 안쪽 벽 뒤로는 완만히 솟고, 카메라 쪽은 바닥 높이로 흘러내립니다.
- **빛**: 횃불·모닥불·마도등 빛을 생성할 때 격자에 구워 정점에 넣고, 실제 조명은 영웅에게 가까운 3개만 켭니다.
- **이야기 소품**: 2번 방 모험가 야영지(삼각대 냄비, 침낭, 상자 탁자와 촛불, 연기), 벽에서 늘어진 뿌리, 바랜 남색 제국 깃발, 발광 버섯, 앞선 모험가의 유골, 보스 방의 마도등. 빨강·보라·금·시안은 적과 조작의 예고 색이라 배경에 쓰지 않습니다.
- **벽 가림**: 카메라와 영웅 사이를 가리는 벽은 디더링으로 녹입니다.
- **물웅덩이**: 화면 텍스처를 일그러뜨려 비추는 회녹색 얕은 물웅덩이를 둡니다. 모바일은 가벼운 버전을 씁니다.
- **소품**: 통, 상자, 술통은 칼날이 지나가면 조각나고, 조각은 한동안 남습니다. 벽 밑에는 MultiMesh로 잔돌을 깔고, 횃불은 깜빡입니다.
- **팔레트**: KayKit 소품이 함께 쓰는 팔레트 아틀라스 한 장을 던전 톤으로 바꿨습니다(`../tools/mute_palette.py`). 배경 소품은 채도를 낮추고 그늘을 중립 회청으로 칠해 낡은 나무로 보이게 합니다.

## 성능 (저사양 아이폰 60fps 목표)

`scripts/boot.gd`가 3D를 SubViewport에서 화면보다 낮은 해상도로 그리고, UI는 원래 해상도로 그립니다.
- **동적 해상도**: 프레임 시간을 재서 60fps를 놓치면 3D 해상도를 바로 낮추고, 3초 동안 지키면 한 단계 올립니다. 휴대폰은 실제 픽셀의 55%에서 시작하고 최대 70%입니다.
- **모바일 설정**: 실시간 그림자와 글로우를 끄고(발밑 원형 그림자만 씀), 먼 횃불 조명은 거리로 끕니다. 텍스처는 VRAM 압축(모바일은 ETC2/ASTC)과 밉맵을 씁니다.
- **주소 옵션**: `?fps`는 프레임 수와 3D 해상도 비율을 보여 주고, `?q=high`, `?q=low`는 품질을 고정합니다.

## 빌드

```sh
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless --path ploh/game --import
$G --headless --path ploh/game --export-release "Web" ../play/index.html
```

스레드 없는 웹 템플릿을 쓰므로 GitHub Pages에서 바로 돌아갑니다. 효과음과 박자 루프는 직접 합성했습니다(`../tools/make_sfx.py`, `../tools/make_music.py`). 개발용 화면 캡처는 `tests/shot.tscn`으로, 박자 입력 자동 테스트(박자마다, 연타, 쉼표 패턴, 급정지)는 `tests/rhythm.tscn`으로 돌립니다(둘 다 내보내기에서는 빠집니다).
