# 프람(프람 베르그) — 불 속성 '불꽃의 용병'

파티 교대용 영웅입니다. 프라우 `astrid/B_mid`와 같은 약 4.5등신, 같은 키 1.25 m(머리 크기를 B_mid와 맞춤), 같은 Meshy 휴머노이드 리그(24본)를 씁니다.

## 버전과 무기
- **불 속성 버전**을 골랐습니다. 일러스트(`ploh/assets/heroes/fram/illust_fire.png`)에서 갈색 긴 머리, 붉은 눈, 붉은 목도리형 케이프, 흰 망토, 검은 원피스, 금색 테두리 은색 갑주가 또렷합니다. 프라우(검은 머리, 노란 조끼)·슈나이더(금발, 하늘색 목도리)와 머리색과 주색이 겹치지 않아 위에서 내려다보는 게임 카메라에서도 구분됩니다. 물 속성(스토리 기본, 검은 머리·파란 옷)은 프라우와 머리색이 같아서 쓰지 않았습니다.
- **무기는 검과 방패**입니다. 검은 일러스트의 듀랜달(금색 원통형 손잡이 장식, 각진 회색 칼날, 붉은 홈)을 한손 브로드소드 크기로 줄였습니다. 방패는 원작 일러스트에 없습니다. 불 속성 프람의 클래스가 가디언이고, 파티 안에서 프라우(한손검)·슈나이더(양손 메이스)와 다른 형태를 만들려고 더했습니다.

## 본
B_mid와 같은 Meshy 휴머노이드 24본입니다.
`Hips` → `Spine02` → `Spine01` → `Spine` → `neck` → `Head` → `head_end`, `headfront`
`Spine` → `LeftShoulder` → `LeftArm` → `LeftForeArm` → `LeftHand` (오른쪽도 같음)
`Hips` → `LeftUpLeg` → `LeftLeg` → `LeftFoot` → `LeftToeBase` (오른쪽도 같음)

손가락 본은 없습니다. Godot는 `weapon_sword`, `weapon_shield`를 각각 `RightHand`, `LeftHand`의 자식 본으로 만들고 메시를 같은 이름의 BoneAttachment3D 아래에 둡니다(B_mid의 `weapon_sword`와 같은 구조).

### 문제
- 공격 1–3타는 Triple Combo Attack(검을 든 모캡) 한 벌을 나눈 것이라 이음매가 정확히 맞습니다. 1·2타는 공격 자세로 끝납니다.
- cast는 Jump Attack(높이 뛰어 내려찍기)입니다. 슈나이더·조슈아의 cast와 같은 원본입니다.
- death의 64–71프레임(누운 뒤)에 검이 머리를 최대 8 cm 지나갑니다. dodge 6프레임도 7 cm 이내입니다.
- 라이브러리 클립은 레퍼런스(예비 150–250 ms, 베기 50–130 ms)보다 예비 동작이 깁니다. 시간 재배치는 게임 코드가 맡습니다.

### 무게 표현
- 예비 동작에서 골반을 뒷발(오른발) 쪽으로 옮기고 무릎을 더 굽혀 체중을 뒤에 싣습니다. 타격에서 골반이 앞발(왼발) 쪽으로 넘어갑니다.
- 예비 → 타격 구간은 가속(t²)으로 보간해 타격 프레임에서 속도가 가장 큽니다. 타격 → 팔로스루 구간은 감속(1 − (1 − t)²)입니다.
- 팔로스루에서 검이 지나쳐 넘어가고 가슴·골반 회전이 검을 따라 더 돌아갑니다. 뒷발 뒤꿈치가 들리며 앞발에 체중이 실립니다.
- 채널마다 시차를 줍니다. 골반은 1.5프레임, 가슴은 0.8프레임, 머리는 2.0프레임, 발은 1.0프레임 먼저 움직이고, 무기 방향은 0.7프레임 늦게 따라옵니다(클립 양 끝 4프레임에서는 시차를 0으로 줄임).

## 무기·손
- `weapon_sword`: 스크립트로 만든 듀랜달입니다. 손잡이 중심에서 칼끝까지 0.725 m(전체 0.82 m), 칼날 0.56 m·폭 9.5 cm, 금색 원통형 손잡이 장식과 청동 띠, 짙은 회색 기계식 날개, 칼날 가운데 붉은 홈. 삼각형 378개. 텍스처 없이 단색 재질(`prop_steel`, `prop_gunmetal`, `prop_gold`, `prop_bronze`, `prop_black`, `prop_red`)만 씁니다. 로컬 축: +Z = 칼날 방향, +X = 날(주먹 마디 쪽), 원점 = 주먹 안 손잡이 중심.
- `weapon_shield`: 30×40 cm 기사 방패(위가 평평하고 아래가 뾰족). 금색 테, 은색 판, 붉은 바탕에 금색 V자 두 개(프람 흉갑 문양), 가죽색 뒷면과 팔 끈 2개. 삼각형 340개. 왼 팔뚝에 끼운 위치(주먹에서 팔꿈치 쪽 5 cm, 손등 바깥 3.5 cm)이고 로컬 +X = 앞면, +Z = 방패 위쪽입니다. 동작 키에서 방패 앞면과 위쪽 방향을 따로 줍니다.
- 손: 손가락 본이 없어서 기본 메시의 손가락 정점을 손바닥 쪽으로 약 145° 말아 양손을 주먹으로 만들었습니다(셰이프 키가 아니라 메시 자체를 고침). 손바닥 방향은 손 정점의 PCA 법선과 'A-pose에서 손바닥이 허벅지를 향함'을 평균해 정했습니다. 오른손 주먹 안으로 검 손잡이가 지나가고, 왼손 주먹은 방패 손잡이를 쥔 모양입니다.

## 정리 결과
- 키 1.25 m(Godot AABB 높이 1.250), 발바닥이 원점(z=0), 수평 중심 정렬, 변환 적용(스켈레톤 스케일 1), glTF +Z 정면
- 삼각형: 몸 30,738 + 검 378 + 방패 340
- 텍스처: 몸 2048² 베이스 컬러 1장(GLB 안 JPEG). 소품은 텍스처 없음
- 노멀 재계산, 스무스 셰이딩
- 망토 색: Meshy가 망토 바깥면을 빨갛게 칠했습니다(3면도는 흰 망토). 망토 면의 UV 영역에서 붉은 픽셀만 같은 명암의 흰색으로 바꿨습니다(약 20.8만 픽셀). 어깨의 붉은 케이프는 3면도대로 남겼습니다.
- 스킨 가중치 보정: Meshy 자동 리깅이 등 뒤 망토·긴 머리를 `LeftArm`(가중치 0.3–0.5)과 허벅지에, 허리 아래 정점 일부를 팔에, 손가락 끝 일부를 허벅지(`RightUpLeg` 1.0)에 묶었습니다. 그대로 두면 방패 팔을 들 때 망토가 따라 올라가고, 손을 움직이면 허벅지에서 손까지 늘어난 면이 생깁니다. 망토·머리는 높이에 따라 척추 사슬(`Hips`–`Spine02`–`Spine01`–`Spine`–`neck`–`Head`)로 옮겼고, 망토 아랫단에는 허벅지 가중치를 30% 섞었습니다. 손가락 끝은 손으로, 턱 아래 옷깃·머리카락의 `Head` 가중치는 `neck`으로 옮겼습니다. 바꾼 정점 주변은 반경 2.5 cm 안의 가중치를 세 번 평균해 경계를 없앴습니다.
- 늘어남 검사: 모든 액션의 모든 프레임에서 쉬는 자세보다 3배 + 1.2 cm 넘게 늘어나고 3.5 cm를 넘는 모서리를 셌습니다. idle, run, attack_1, attack_2, cast, spin, hit, death는 0개, attack_3은 8프레임에 2개(최대 9.4 cm), dodge는 27프레임에 9개(최대 6.9 cm, 어깨 뒤)입니다.
- Blender 헤드리스(5.0.1)로 처리했습니다. 실행 중인 Blender 세션은 쓰지 않았습니다.

## 문제
- 주먹은 메시만 구부린 것이라 가까이서 보면 손가락이 손잡이를 조금 뚫거나 뜹니다. 게임 카메라 거리에서는 주먹으로 보입니다.
- 망토 옆 가장자리에 붉은 띠가 조금 남았습니다(안감처럼 보임).
- 망토·머리카락에는 천 시뮬레이션이나 별도 본이 없습니다. 척추·골반에 붙어 있어 큰 동작에서 다리가 망토 안쪽을 뚫을 수 있습니다.
- dodge/hit/death는 Meshy 몸동작에 팔만 덮어쓴 것입니다. 루트 이동이 들어 있어 Hips가 움직입니다(dodge 약 1.9 m, hit·death 약 0.6 m. B_mid와 같은 클립).
- 직접 만든 동작은 키포즈 + 2본 IK라 모캡보다 딱딱하고 발이 약간 미끄러질 수 있습니다. spin은 발도 같이 돕니다.
- 방패는 원작에 없는 소품입니다. 원작 듀랜달은 더 크고 기계적인 대검에 가깝지만 방패와 함께 쓰려고 한손 크기로 줄였습니다.
