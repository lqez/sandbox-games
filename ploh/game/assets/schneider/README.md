# 슈나이더 — 물 속성 '온화한 수인기사'

파티 교대용 영웅입니다. 프라우 `astrid/B_mid`와 같은 약 4.5등신, 같은 키 1.25 m(머리 크기를 B_mid와 맞춤), 같은 Meshy 휴머노이드 리그(24본)를 씁니다. 원작의 슈나이더는 108 cm로 작지만, 파티를 같은 비율로 통일하려고 B_mid와 같은 키로 맞췄습니다. 대신 3면도에서 다부지고 어깨가 넓은 체형으로 그렸습니다.

## 버전과 무기
- **물 속성 버전**을 골랐습니다. 일러스트(`ploh/assets/heroes/schneider/illust_water.png`)에서 꿀색 금발, 갈색 처진 개 귀, 하늘색 목도리와 은색 장식, 흰 반소매 셔츠, 갈색 가죽 조끼, 검은 반바지가 또렷합니다. 불 속성(갈색 머리, 흰 튜닉, 붉은 목도리, 은색 투구)은 프람(불 속성)과 붉은색이 겹치고, 프라우(검은 머리)·프람(갈색 머리)과 머리색도 비슷해집니다. 물 속성은 금발과 하늘색으로 위에서 내려다봐도 셋이 구분됩니다.
- **무기는 양손 대형 가시 메이스**입니다. 두 일러스트 모두 긴 자루 끝에 원통형 가시 머리가 달린 큰 메이스를 어깨에 메고 있습니다(불은 붉은 자루, 물은 파란 자루). 물 속성 색인 파란 자루로 만들었습니다. 파티에서 '무거운 무기' 역할을 맡아 프라우(한손검)·프람(검과 방패)과 대비됩니다.

## 본
B_mid와 같은 Meshy 휴머노이드 24본입니다.
`Hips` → `Spine02` → `Spine01` → `Spine` → `neck` → `Head` → `head_end`, `headfront`
`Spine` → `LeftShoulder` → `LeftArm` → `LeftForeArm` → `LeftHand` (오른쪽도 같음)
`Hips` → `LeftUpLeg` → `LeftLeg` → `LeftFoot` → `LeftToeBase` (오른쪽도 같음)

손가락 본과 꼬리 본은 없습니다. Godot는 `weapon_mace`를 `RightHand`의 자식 본으로 만들고 메시를 같은 이름의 BoneAttachment3D 아래에 둡니다(B_mid의 `weapon_sword`와 같은 구조).

### 문제
- 라이브러리에 양손 메이스 동작이 따로 없어서 Attack·Heavy Hammer Swing·Charged Ground Slam 등 양손 무기 모캡에 왼 주먹을 자루에 붙이는 IK(`ploh/tools/mocap/twohand.py`)를 걸었습니다. 팔이 짧은 프레임은 오른손(무기 방향 유지)을 최대 약 30 cm 몸 쪽으로 당깁니다.
- attack_1의 내려치기는 4프레임(31–34) 동안 메이스가 머리 위를 지나가는 매우 빠른 호입니다.
- 주먹은 이전과 같은 메시 고침이라 가까이서 보면 손가락이 자루 위를 갈고리처럼 덮습니다(이전 버전과 같은 수준).
- 라이브러리 클립은 레퍼런스(예비 150–250 ms, 베기 50–130 ms)보다 예비 동작이 깁니다. 시간 재배치는 게임 코드가 맡습니다.

### 재현
- Meshy 요청: `uv run --no-project --with requests python ploh/tools/heroes/meshy.py schneider anim <action_id,...> <태그>` (`raw/animations_<태그>.glb`)
- GLB·사이드카: `uv run --no-project --with numpy python ploh/tools/mocap/mocap_build.py schneider` (클립 표는 이 스크립트의 `SPEC`, 몸 감축은 `decimate_body.py`를 헤드리스 Blender로 실행, 검사는 `qa.py`)

### 무게 표현
프람과 같은 방식(clips_fram.py)에 무거운 무기 쪽으로 다음을 더 줬습니다.
- 예비 동작이 깁니다. attack_1 기준 가속이 시작되기 전까지 0–13프레임(0.43 s, 클립의 33%)으로 프람(0–7프레임, 0.23 s)의 약 두 배이고, 끝 2프레임은 '버팀'이라 무게에 메이스 머리가 살짝 처집니다. 타격은 클립의 45% 지점입니다.
- 무릎을 더 깊이 굽힙니다(골반을 최대 15–20 cm 낮춤, 프람은 10–15 cm).
- attack_1·2 기준 가속(t²) 구간이 4프레임, 팔로스루(1 − (1 − t)²)가 6프레임입니다. 팔로스루에서 메이스가 몸 반대편까지 넘어가며 골반이 45°, 가슴이 40°까지 끌려 돕니다.
- 안착 단계에서 메이스 머리가 아래로 떨어지고, 복귀는 12프레임(0.4 s)으로 프람(8프레임)보다 느립니다.
- 채널 시차는 프람과 같습니다(골반 1.5, 가슴 0.8, 머리 2.0, 발 1.0프레임 먼저, 무기 0.7프레임 늦게).

### 타격 판정 범위

## 무기·손
- `weapon_mace`: 스크립트로 만든 양손 가시 메이스입니다. 전체 1.245 m(자루 끝에서 오른손 손잡이 중심까지 0.43 m, 오른손에서 꼭대기 가시 끝까지 0.815 m). 파란 자루(반지름 2.1 cm)와 금색 띠 2개, 은색 깃과 자루 끝 마개, 길이 32 cm·반지름 8.5 cm 원통형 은색 머리, 짙은 회색 테 2개, 가시 22개(7개씩 3줄 + 꼭대기 1개, 길이 7–7.5 cm). 삼각형 580개. 텍스처 없이 단색 재질(`prop_steel`, `prop_gunmetal`, `prop_gold`, `prop_blue`)만 씁니다. 로컬 축: +Z = 머리 방향, 원점 = 오른손 주먹 안 손잡이 중심.
- 양손 파지: 동작 키는 두 주먹 사이 중심(`gc`, 양 어깨 가운데 기준)과 자루 방향(`rb`)으로 줍니다. 팔이 짧아서(어깨~손목 0.28 m) 손이 닿지 않는 프레임은 손잡이 중심을 가슴 앞쪽으로 당깁니다(174프레임, 최대 17 cm). 왼손이 자루에서 벗어난 거리는 attack_3의 34프레임이 12.7 mm로 가장 크고, attack_3 외의 클립은 3.5 mm 이하입니다.
- 손: 손가락 본이 없어서 기본 메시의 손가락 정점을 손바닥 쪽으로 약 145° 말아 양손을 주먹으로 만들었습니다(셰이프 키가 아니라 메시 자체를 고침). 손바닥 방향은 손 정점의 PCA 법선과 'A-pose에서 손바닥이 허벅지를 향함'을 평균해 정했습니다. 두 주먹 안으로 자루가 지나갑니다.

## 문제
- 주먹은 메시만 구부린 것이라 가까이서 보면 손가락이 자루를 조금 뚫거나 뜹니다. 게임 카메라 거리에서는 주먹으로 보입니다.
- 목·어깨(목도리와 귀가 만나는 곳)와 꼬리 뿌리는 큰 동작에서 면이 5–10 cm 늘어납니다. 특히 Meshy hit 동작의 머리가 크게 젖혀지는 프레임에서 눈에 띌 수 있습니다.
- 꼬리에는 본이 없어 골반에 고정되어 흔들리지 않습니다.
- 팔이 짧아 양손 자세를 그대로 낼 수 없는 프레임은 손잡이를 몸 쪽으로 당겼습니다. 그래서 일부 키포즈는 스크립트 값보다 메이스가 몸에 가깝습니다.
- dodge/hit/death는 Meshy 몸동작에 팔만 덮어쓴 것입니다. 루트 이동이 들어 있어 Hips가 움직입니다(dodge 약 1.9 m, hit·death 약 0.6 m. B_mid와 같은 클립). 구르기에서 메이스가 바닥이나 다리와 겹치는 프레임이 있을 수 있습니다.
- 직접 만든 동작은 키포즈 + 2본 IK라 모캡보다 딱딱하고 발이 약간 미끄러질 수 있습니다. spin은 발도 같이 돕니다.
- attack_3 내려찍기에서 가시 끝이 바닥 아래로 최대 1.6 cm 들어갑니다.
